FID (lower is better)
Precision (fidelity): generated points inside the real manifold
Recall (coverage): real points inside the generated manifold

FID fits one Gaussian to each set and adds a mean term and a covariance term. Precision and recall approximate the region covered by a set (its manifold) by a ball around every point, reaching to its 3rd nearest neighbour within the same set. Real and generated sets have the same number of points. The values of this 2D toy example are not comparable to FIDs reported in papers.
