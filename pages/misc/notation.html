Mathematical Notation

Author
Affiliation

Marco Willi

Institute for Data Science I4DS, FHNW

The notation follows the Deep Learning Book (Goodfellow et al. 2016) where possible. Deviations and course-specific symbols are listed at the end of this page.

1 Numbers and Arrays

Syntax Description
\(a\) A scalar (integer or real)
\(\mathbf{a}\) A vector
\(\mathbf{A}\) A matrix
\(\mathbf{\mathsf{A}}\) A tensor
\(\mathbf{I}_n\) Identity matrix with \(n\) rows and \(n\) columns
\(\mathbf{I}\) Identity matrix with dimensionality implied by context
\(\mathbf{0}\) Vector of zeros with dimensionality implied by context
\(\mathbf{e}^{(i)}\) Standard basis vector \([0,\dots,0,1,0,\dots,0]\) with a 1 at position \(i\)
\(\text{diag}(\mathbf{a})\) A square, diagonal matrix with diagonal entries given by \(\mathbf{a}\)
\(\textnormal{a}\) A scalar random variable
\(\mathbf{a}\) A vector-valued random variable
\(\theta\) Parameters of a model

2 Sets

Syntax Description
\(\mathcal{A}\) A set
\(\mathbb{R}\) The set of real numbers
\(\mathbb{R}^{d}\), \(\mathbb{R}^{m \times n}\) The set of real vectors with \(d\) entries, of real matrices with \(m\) rows and \(n\) columns
\(\{0, 1, \dots, n\}\) The set of all integers between \(0\) and \(n\)
\([a, b]\) The real interval including \(a\) and \(b\)
\((a, b]\) The real interval excluding \(a\) but including \(b\)

3 Indexing

Syntax Description
\(a_i\) Element \(i\) of vector \(\mathbf{a}\), with indexing starting at 1
\(A_{i,j}\) Element \(i, j\) of matrix \(\mathbf{A}\)
\(\mathbf{A}_{i,:}\) Row \(i\) of matrix \(\mathbf{A}\)
\(\mathbf{A}_{:,i}\) Column \(i\) of matrix \(\mathbf{A}\)
\(\mathbf{\mathsf{A}}_{i,j,k}\) Element \((i, j, k)\) of a 3-D tensor \(\mathbf{\mathsf{A}}\)
\(\mathbf{W}^{(l)}\), \(\mathbf{h}^{(l)}\) Weights and activations of layer \(l\)

4 Linear Algebra Operations

Syntax Description
\(\mathbf{A}^\top\) Transpose of matrix \(\mathbf{A}\)
\(\mathbf{A} \odot \mathbf{B}\) Element-wise (Hadamard) product of \(\mathbf{A}\) and \(\mathbf{B}\)
\(\det(\mathbf{A})\) Determinant of \(\mathbf{A}\)
\(\operatorname{tr}(\mathbf{A})\) Trace of \(\mathbf{A}\)

5 Calculus

Syntax Description
\(\frac{dy}{dx}\) Derivative of \(y\) with respect to \(x\)
\(\frac{\partial y}{\partial x}\) Partial derivative of \(y\) with respect to \(x\)
\(\nabla_{\mathbf{x}} y\) Gradient of \(y\) with respect to \(\mathbf{x}\)
\(\frac{\partial f}{\partial \mathbf{x}} \in \mathbb{R}^{m \times n}\) Jacobian matrix of \(f: \mathbb{R}^n \rightarrow \mathbb{R}^m\)
\(\int f(\mathbf{x}) \, d\mathbf{x}\) Definite integral over the entire domain of \(\mathbf{x}\)

6 Probability and Information Theory

Syntax Description
\(P(x)\) A probability distribution over a discrete variable
\(p(x)\) A probability distribution over a continuous variable or over a variable whose type has not been specified
\(p(\mathbf{x} \mid \mathbf{y})\) Conditional distribution of \(\mathbf{x}\) given \(\mathbf{y}\)
\(\mathbf{x} \sim p\) \(\mathbf{x}\) is sampled from (has distribution) \(p\)
\(\mathbb{E}_{\mathbf{x} \sim p} [ f(\mathbf{x}) ]\) Expectation of \(f(\mathbf{x})\) with respect to \(p(\mathbf{x})\)
\(D_{\mathrm{KL}}(P \,\Vert\, Q)\) Kullback-Leibler divergence of \(P\) and \(Q\)
\(\mathcal{N}(\mathbf{x}; \mathbf{\mu}, \mathbf{\Sigma})\) Gaussian distribution over \(\mathbf{x}\) with mean \(\mathbf{\mu}\) and covariance \(\mathbf{\Sigma}\)
\(\mathcal{N}(x; \mu, \sigma^2)\) Gaussian distribution over \(x\) with mean \(\mu\) and variance \(\sigma^2\)
\(\mathbf{z} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})\) \(\mathbf{z}\) is sampled from a standard Gaussian

7 Functions

Syntax Description
\(f: \mathcal{A} \rightarrow \mathcal{B}\) The function \(f\) with domain \(\mathcal{A}\) and range \(\mathcal{B}\)
\(f \circ g\) Composition of the functions \(f\) and \(g\)
\(f_\theta(\mathbf{x})\) A function (model) of \(\mathbf{x}\) with parameters \(\theta\)
\(\log x\) The natural logarithm of \(x\)
\(\sigma(x)\) Logistic sigmoid, \(\frac{1}{1 + \exp(-x)}\)
\(\mathrm{softmax}(\mathbf{z})\) Softmax, \(\mathrm{softmax}(\mathbf{z})_k = \frac{\exp(z_k)}{\sum_{j=1}^K \exp(z_j)}\)
\(\mathrm{ReLU}(x)\) Rectified linear unit, \(\max(0, x)\)
\(\lVert \mathbf{x} \rVert_p\) \(L^p\) norm of \(\mathbf{x}\)
\(\lVert \mathbf{x} \rVert\) \(L^2\) norm of \(\mathbf{x}\)
\(\lfloor x\rfloor\) \(x\) rounded down to the nearest integer
\(\arg\min_{\theta} f(\theta)\) The value of \(\theta\) that minimizes \(f(\theta)\)

8 Datasets and Learning

Syntax Description
\(N\) Number of training examples
\(d\) Number of input features (dimensionality of \(\mathbf{x}\))
\(K\) Number of classes
\(\mathcal{D} = \{(\mathbf{x}^{(i)}, y^{(i)})\}_{i=1}^N\) A training set
\(\mathbf{x}^{(i)}\) The \(i\)-th training example
\(y^{(i)}\), \(\mathbf{y}^{(i)}\) The target (label or label vector) of the \(i\)-th training example
\(\hat{y}\), \(\hat{\mathbf{y}}\) A model prediction
\(\mathbf{X} \in \mathbb{R}^{N \times d}\) The design matrix, with example \(\mathbf{x}^{(i)}\) in row \(\mathbf{X}_{i,:}\)
\(p_{\text{data}}\) The data-generating distribution
\(L(\hat{y}, y)\) Loss of a single example
\(J(\theta)\) Cost (objective): the loss averaged over the training set
\(\theta^*\) Optimal parameters, \(\theta^* = \arg\min_{\theta} J(\theta)\)

9 Course-Specific Notation

The following symbols are not covered by the Deep Learning Book.

9.1 Images and CNNs

Syntax Description
\(C \times H \times W\) Shape of an image or activation map: channels, height, width
\(N \times C \times H \times W\) Shape of a batch of \(N\) images (NCHW, the format used by PyTorch)
\(C_{in}\), \(C_{out}\) Number of input and output channels of a layer
\(i\), \(o\) Spatial input and output size of a convolution
\(k\), \(s\), \(p\), \(d\) Kernel size, stride, padding, dilation
\(K * I\) Convolution (implemented as cross-correlation) of input \(I\) with kernel \(K\)
\(r_0\) Receptive field size

9.2 Representation Learning

Syntax Description
\(\mathbf{z} = f(\mathbf{x})\) Representation (embedding) of \(\mathbf{x}\)
\(\mathrm{sim}(\mathbf{z}_i, \mathbf{z}_j)\) Similarity of two representations, usually cosine similarity
\(\tau\) Temperature

9.3 Generative Models

Syntax Description
\(p_\theta(\mathbf{x})\) Model distribution with parameters \(\theta\)
\(\mathbf{z}\) Latent variable / random input of a generative model
\(\mathbf{c}\) Condition (e.g. class label, text prompt)
\(g\), \(d\) Generator, discriminator
\(q_\psi(\mathbf{z} \mid \mathbf{x})\) Encoder (approximate posterior) of a VAE
\(\mathbf{x}_t\), \(T\) Sample at time step \(t\), number of time steps (diffusion, flows)
\(\mathbf{\epsilon}\) Gaussian noise
\(v_\theta(\mathbf{x}_t, t)\) Velocity field (flow matching)

10 Deviations from the Deep Learning Book

  • Models are written as \(f_\theta(\mathbf{x})\) instead of \(f(\mathbf{x}; \theta)\), as in most of the generative modelling literature.
  • The number of training examples is \(N\) (instead of \(m\)) and the number of input features is \(d\) (instead of \(n\)).
  • Sets are calligraphic (\(\mathcal{D}\)) instead of blackboard bold.
  • Vectors and matrices are upright bold (\(\mathbf{x}\), \(\mathbf{X}\)) instead of bold italic.
  • Pairs of examples in similarity and contrastive formulas are written as \(\mathbf{z}_i, \mathbf{z}_j\) instead of \(\mathbf{z}^{(i)}, \mathbf{z}^{(j)}\), following the original papers.
  • Named objectives from papers keep their symbol, e.g. \(\mathcal{L}_{\text{InfoNCE}}\).
  • Time steps of diffusion models and flows are subscripts (\(\mathbf{x}_t\)) instead of superscripts (\(\mathbf{x}^{(t)}\)).

References

Goodfellow, Ian, Yoshua Bengio, and Aaron Courville. 2016. Deep Learning. MIT Press.
